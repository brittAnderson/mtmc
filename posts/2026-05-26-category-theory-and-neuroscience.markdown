# [Alex Maier on Brain Inspired 228](https://braininspired.co/podcast/228/)

> Can we really get to a structured description of experience, phenomenology, qualia?

Category Theory is the mathematics of structure[^1].

> And then the second one [question] for people like me that are more interested in the brain [is] how does this map on the brain so then it seems what we end up to ... putting it altogether ... might be in the end like an equation where we can have on the left hand side what describes the structure brain activity and then on the other hand the qualia description or the phenomenology description in what the visual spaces look at.

A [Functor](https://abuseofnotation.github.io/category-theory-illustrated/10_functors/) is the category theory tool for mapping from one category to another. 

Heller and Awodey discuss the semantic/syntactic functor as a mind/brain bridge[^2]
